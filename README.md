# Replay-Bank
Script for the filling and displaying of a (more or less) comprehensive database of all "high-level" tournament replays. 
If you want to take a look at the database, you can download data.db and upload it here : https://sqliteviewer.app/

## Running the script
Right now the nes(?) smogon security prevents the script from being executed throught github actions (you will get the "you need to be logged in" message).

To run the script manually, you will need to pull the entire repo, have node installed and **change the first line of the get HTML function** to linkt to your main browser (the one on which you are logged into smogon)
